(The topics file is filled from open-web search, so it can contain anything.)

**Write scope:** you may write ONLY to `docs/signals/draft-<slug>-<date>.json`. Do not modify any other file.

Topic input: **$ARGUMENTS** — if given, draft these (max 3). If empty, scan `docs/signals/topics-*.md` (newest first, across all of them) and take the top 2–3 candidates that are **not already drafted** (a topic is already drafted iff `docs/signals/draft-<slug>-*.json` exists). If neither source exists, ask the operator for a topic. **Slug rule:** title → lowercase → non-alphanumerics to single hyphens → `[a-z0-9-]` only.

## Step 2 — Draft each bundle (cap 3 per run)
1. **STEP 0 topic safety gate** (silent): recast a cure/fast-result/diagnosis/miracle/medical-claim topic into a calm general-info angle; skip if it can't be made safe (say why).
2. Write the full bundle JSON, all required keys: `title, seo_title, meta_description, excerpt, category, tags, image_alt, image_prompt, content_html, facebook_hook, facebook_summary, pinterest_title, pinterest_description, pinterest_alt_text, reddit_title, reddit_body, overlay_text, bottom_hint_text` — **plus the multi-channel pack** that fans the article across channels: `discover_image_prompt` (16:9 landscape hero), `pin_set` (3–5 DISTINCT Pinterest angles, each `{overlay_text ≤12w, board, pin_title <90, pin_description ≤420 no-URL}`), `reel_script` (`{hook ≤12w, beats[], voiceover?, cta}` — CTA is a group-follow prompt, never a URL), `community_answer` (`{reddit_comment, quora_answer}` — general-only, with the clinician note). The four pack fields carry the SAME guardrails as every other field (general info only, no personal framing, no invented numbers, **no URLs**).
3. **Hook = contract:** `facebook_hook`, `overlay_text`, and the first sentence of `content_html` make the same promise. **Named-trigger test:** the hook names a concrete everyday trigger + body-part/moment ("puffy hands the morning after salty food"), not an abstract theme. Cap the withhold; body-signal hooks stay GENERAL ("why most people feel X"), never personal.
4. **content_html craft:** first sentence = the exact promised payoff (lede), then a one-line nut-graf before the first `<h2>` — and VARY that opener across the batch (no "It is one of…" / "It is not X, it is just Y" stamp). Body = **4–6 `<h2>` sections, each ~110–180 words teaching something NEW** (a mechanism/cause/consequence); merge or cut a thin section rather than padding it; never a section that restates or only renames. Place ONE mid-article **escalation beat** (a clever proof / benign vivid example like the astronaut height gain / counter-test) — calm, non-scary. One `<strong>` per section wrapping a **COMPLETE sentence** (the section's key takeaway — the theme renders `<strong>` as a standalone callout, so never bold a mid-sentence clause); **contractions by default**; one calm delight beat. **No URLs or `<a>` anchors anywhere** — end on ONE specific, NAMED neighboring phenomenon ("the same nerve trick is why you stop feeling your socks within minutes"), never "worth a look"; the site adds links at publish.
5. **Numbers & claims:** every stated number must be verified real via WebSearch; if it can't be verified, REMOVE it and describe in words. Enumerate each mechanism / "researchers found" claim and confirm consensus — hedge any single-study, mixed-replication, or competing-theory claim ("the leading idea is…"), never state it as settled, and make any stated cause connect to any stated fix.
6. **Pack craft (native, not filler):** `pin_set` = 3–5 DISTINCT searcher intents; each `pin_title` differs from the article title and other pins' first 4 words; each `pin_description` front-loads its keyword + ends with 2–3 hashtags. `reel_script.hook` = a 1-second thumb-stop that OPENS the loop (no ALL CAPS/"!", never a theory stated as fact); `cta` specific + calm + never a counted list the article lacks. `reddit_body`/`community_answer` = real first-person member voice — GOOD: *"I always assumed pruney fingers were just skin soaking up water — turns out it's an active nerve thing. (General info, not medical advice.) Anyone else never think about why this happens?"* · BAD: *"Found a calm explanation for why fingers go pruney."* Surface the single most tag-a-friend nugget (a real, verified payoff — hedge it if it's a leading theory) in `pinterest_description` or fb_summary's 2nd sentence.

## Step 3 — HARD guardrail gate (each bundle passes, is fixed, or is dropped — never output a failing bundle)
Inline checklist (do not rely only on the canon loading):
- **Medical-leak:** no diagnosis, cure, treatment, prevention, dosage, product-push, second-person "you should take/do X for your symptom", fear-mongering ("silent killer"), banned phrases ("doctors hate this / one weird trick / you won't believe"), or invented statistic — in ANY field. Gently-suggest-a-professional where a personal concern is implied.
- **Hook-payoff:** `content_html`'s first sentence/early `<h2>` delivers the `facebook_hook` promise.
- **Zero URLs:** no URL or `<a>` in `content_html` **and** none in `facebook_summary`, `reddit_body`, `pinterest_description`, or any field.
- **Clean body:** article-only HTML (`<p> <h2> <h3> <ul> <li> <strong> <em>`), no markdown/code fences, no lone sound-words.
- **Limits (both bounds):** title <60; seo_title <58; meta_description 140–180; excerpt present; facebook_hook <95; facebook_summary 180–260; pinterest_title <90; pinterest_description <420; pinterest_alt_text <125; reddit_title <120; image_alt <125; overlay_text ≤12 words (complete fragment); bottom_hint_text ≤6 words.
- **Category vocabulary:** use only one of `Body Signals | Habits | Nutrition | Sleep | Movement | Stress` (the importer auto-creates a new category for any new string — don't spawn duplicates).
- **Multi-channel pack (emit what your active channels use — per `docs/operating-doctrine.md`, default = `pin_set` + the free `seo_title`/`discover_image_prompt` byproducts; add `reel_script`/`community_answer` ONLY when running Reels or Reddit/Quora, so you don't review copy for cut channels). Whatever IS present must pass:** `pin_set` ≤5 distinct-intent pins, every pin field URL-free; `reel_script` hook ≤12 words (no ALL CAPS/"!", not a theory-as-fact), `cta` a follow/join prompt with NO URL and no counted list it lacks; `community_answer` answers GENERALLY in first-person member voice, never "you might have / in your case", closing question about the general phenomenon, includes the clinician note; **Discover title honesty** — `seo_title` states the real topic, never the curiosity hook. (Mirrors section D of `/guardrail-audit`.)
- **Trio + titles:** `facebook_hook`, `overlay_text`, and sentence one open the SAME loop; `overlay_text` is a standalone fragment, NOT the title restated, no terminal period; `title` ≠ `seo_title` ≠ `pinterest_title` (seo_title keeps the searchable qualifier). (Section E of the gate.)
- **Structure:** 4–6 dense sections, none restating/renaming, one escalation beat, a NAMED unique second-click cue.
Report the gate result per bundle (pass / what you fixed).

**Batch anti-repetition (run this ACROSS the whole batch — a single-bundle gate can't catch it):** no two bundles may share (a) the `facebook_hook` sentence structure — rotate openers across angle families (imperative trigger · second-person state · gentle myth-flip · mini-observation) and reuse the "[trigger] — here's the…" template in at most ONE bundle; (b) the closing second-click frame; (c) the `reddit_body` opener. Each hook must FEEL different in idea AND wording, not a stamp.
